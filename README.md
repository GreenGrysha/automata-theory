## Часть 1. Построение регулярного выражения и конечного автомата для L7

### 1.1. Построение регулярного выражения

Язык $L7 = \{vwv : v,w \in \{a,b\}^*, |v|=2\}$ задает цепочки, у которых первые два символа совпадают с последними двумя, а между ними стоит произвольная (в т.ч. пустая) строка $w$. Минимальная длина цепочки языка — 4 символа (при $w = \lambda$).

Поскольку $v$ может принимать ровно 4 значения ($aa$, $ab$, $ba$, $bb$), язык распадается на объединение 4 непересекающихся по первым двум символам подъязыков:

$$L7 = aa(a+b)^*aa \;+\; ab(a+b)^*ab \;+\; ba(a+b)^*ba \;+\; bb(a+b)^*bb$$

## Часть 2. Регулярная грамматика

### 2.1. Построение праволинейной грамматики

Для языка $L7$ составлена следующая праволинейная грамматика (по одной ветви нетерминалов на каждое значение $v$):

* $S \to aaA \mid abB \mid baC \mid bbD$
* $A \to aA \mid bA \mid aa$
* $B \to aB \mid bB \mid ab$
* $C \to aC \mid bC \mid ba$
* $D \to aD \mid bD \mid bb$

Стартовое правило $S$ фиксирует первые два символа цепочки и одновременно выбирает, в какую из 4 ветвей ($A$, $B$, $C$ или $D$) переходит вывод. Каждый нетерминал $A/B/C/D$ обеспечивает генерацию произвольной подстроки $w \in \{a,b\}^*$ (рекурсивные правила $\to aX \mid bX$) и завершает вывод терминальной строкой, равной зафиксированному $v$ (правила $A \to aa$, $B \to ab$, $C \to ba$, $D \to bb$).

### 2.2. Построение КА по грамматике (Convert to FA)

Преобразование выполнено по стандартному алгоритму:
* Каждому нетерминалу сопоставлено состояние автомата ($S \to q_0$, $A \to q_1$, $B \to q_2$, $C \to q_3$, $D \to q_4$);

## Часть 3. Доказательство нерегулярности языка (лемма о разрастании)

**Язык:** $L_{33} = \{\,w\,w\,w\,w^R : w \in \{a,b\}^*\,\}$, где $w^R$ — реверс строки $w$.

**Утверждение.** Язык $L_{33}$ не является регулярным.

### Доказательство

Предположим противное: пусть $L_{33}$ регулярен. Тогда по лемме о разрастании для регулярных языков существует константа накачки $p \ge 1$ такая, что любое слово $s \in L_{33}$ длины $|s| \ge p$ можно представить в виде $s = xyz$, где:

- $|xy| \le p$;
- $|y| \ge 1$;
- $x y^i z \in L_{33}$ для любого $i \ge 0$.

**1. Выбор слова.** Возьмём $w = a^n b$, где $n = p$. Тогда $w^R = b a^n$, и

$$s = w\,w\,w\,w^R = a^n b \cdot a^n b \cdot a^n b \cdot b a^n, |s| = 4(n+1) \ge p.$$

**2. Анализ подстроки $y$.** По условию леммы $|xy| \le p = n$, поэтому подстрока $xy$ целиком лежит внутри первого блока $a^n$ (до первой буквы $b$). Значит,

$$y = a^k, 1 \le k \le n.$$

**3. Накачка при $i = 0$.** Удаляя $y$, получаем

$$s' = xy^0z = a^{\,n-k}\, b\, a^{n}\, b\, a^{n}\, b\, b\, a^{n},  |s'| = 4n + 4 - k.$$

**4. Проверка принадлежности $s'$ языку.** Если $s' \in L_{33}$, то $s' = w'w'w'w'^{R}$ для некоторого $w' \in \{a,b\}^*$.

Подсчитаем число вхождений символа $b$ в обеих записях:
- в $s'$ — оно равно $4$ (неизменно относительно накачки, так как $y$ состояла только из $a$);
- в $w'w'w'w'^{R}$ — оно равно $4 \cdot (\text{число } b \text{ в } w')$.

Отсюда $w'$ содержит ровно одну букву $b$, то есть

$$w' = a^i\, b\, a^j,  i, j \ge 0.$$

**5. Сравнение промежутков между буквами $b$.** Подставив $w'$, строка $w'w'w'w'^{R}$ даёт последовательность из четырёх букв $b$ с промежутками между ними (считая до первой и после последней):

$$i,\ \ i+j,\ \ i+j,\ \ 2j,\ \ i.$$

В нашей же строке $s'$ промежутки между четырьмя буквами $b$ равны:

$$n-k,\ \ n,\ \ n,\ \ 0,\ \ n.$$

Приравнивая крайние члены последовательностей:

$$i = n-k \quad\text{(из первого промежутка)},  i = n \quad\text{(из последнего промежутка)}.$$

Отсюда $n - k = n \Rightarrow k = 0$.

**6. Противоречие.** По условию леммы $k \ge 1$, а мы получили $k = 0$ — противоречие. Значит, ни при каком допустимом разбиении $s = xyz$ условие $xy^0z \in L_{33}$ не выполняется, что нарушает лемму о разрастании.

### Вывод

Полученное противоречие опровергает исходное предположение о регулярности. Следовательно,
$L_{33} \text{ не является регулярным языком.}$
