# Практика 1 (вариант 1)
## ДКА
### Задание 
Построить ДКА, допускающий в алфавите {a, b} все строки с 
количеством символов a, не превышающем 3.
### Реализация 
Файлы с ДКА (реализация + .jff файл) находятся в папке dfa проекта
## НКА
### Задание 
Построить НКА, допускающий цепочки в алфавите Z = {1, 2, 3}, у которых 
последний символ цепочки уже появлялся в ней раньше, например w = 12321.
### Реализация 
Файлы с НКА (реализация + .jff файл) находятся в папке nfa проекта
## Запуск
Запуск происходит через main.py в корневой папке проекта
